# Silicon Simile

The Abhidhamma read through the machine, and the places where the machine breaks.

Written by Miss Aquarius℠. Foreword by Thon Ly. Part of the library at [book.thonly.org](https://book.thonly.org).

## Why this repository exists

A record is only worth reading if it can be shown to have existed when it says it did. Every document here is
committed and timestamped, and the timestamps can be checked without trusting this repository, GitHub or the
author. See [`TIMESTAMPS.md`](./TIMESTAMPS.md).

## What goes here

| Path | What it holds | Written |
|---|---|---|
| `GLOSSARY.md` | The simile, term by term. Every Pāli term is cited to a line of the Chaṭṭha Saṅgāyana text, and every place the simile breaks is kept beside the places it holds | As the simile grows |
| `OUTLINE.md` | The book's plan: five parts, eighteen chapters, each answering one question, and what must happen before the first edition | Before the chapters |
| `chapters/` | The book, as it is written | As each chapter is finished |
| `foreword.md` | Thon Ly's foreword, in his own words | Once |
| `corrections/` | Readers' corrections, one file each, never edited: the passage, what is wrong, the decision and why, and the edition that carries it | As readers send them |

Files are versioned, never silently rewritten. A revised file keeps its earlier proof under a new name (`<file>.rN.ots`), and each revision is logged in `TIMESTAMPS.md`.

## The simile is a reading aid, never an input

The simile helps a reader understand what the Abhidhamma says. It is never used to decide what the Abhidhamma
says: the formal Abhidhamma at [SiliconWat/formal-abhidhamma](https://github.com/SiliconWat/formal-abhidhamma)
refuses the simile's vocabulary in anything a blind reader sees, so a computer metaphor can never bend a
derivation (`scripts/simile_guard.py` there).
