# Corrections

This book is improved in the open. Anyone who finds an error in it, in the texts, the Pāli, the computing, or the
simile itself, is invited to say so. Pāli and Abhidhamma scholars, computer scientists and practitioners are the
readers it most needs.

## How a correction is kept

Each correction is one file here, written once and never edited. It records:

- **the passage**: the chapter, and the words corrected
- **what is wrong**, as the reader put it
- **the decision**: accepted, accepted in part, or declined, and why
- **the edition** that carries the change

A later decision on the same correction is a new, dated file that names the one it follows. Nothing here is deleted.

A contributor is named only with their consent. Nobody is paid for a correction, and nobody pays to make one. The book
is free.
